# 文体の実例と点検項目

## 実例の扱い

以下の短い表現は、同じ題を複数のAIに執筆させて公開した[比較企画](https://qiita.com/robitan/items/c94130eddad69696dd9c)の生成記事と、[AIを使ったと明示された記事](https://pantograph.co.jp/blog/production/ai-writting.html)で確認したもの。語句自体を禁止しない。複数箇所に現れ、書き手の考えや対象固有の情報を押しのけている場合に指摘する。比較企画のサンプルは一つの題材・条件であり、一般的な出現率やモデルの鑑定には使えない。

| 見る癖 | 公開された生成・AI利用記事に見られる短い例 | 問題になる条件 |
| --- | --- | --- |
| 読者を案内する定型文 | 「〜について探っていきましょう」「本記事では〜を解説」 | 導入で長く予告し、本文でしか分からないことが少ない |
| 過度な留保 | 「〜と言えるでしょう」「〜と考えられます」 | 根拠を示せる箇所でも判断を曖昧にし続ける |
| 定型的な強調 | 「重要なのは〜」「注目すべき点として〜」 | どの段落も同じ強さで始まり、実際の重要度が見えない |
| 列挙の機械化 | 「第一に」「第二に」「最後に」 | 内容に必要な区分ではなく、各節・各ページが同じ型になる |
| 空疎な締め | 「いかがでしたでしょうか」「お役に立てれば幸いです」 | 作品や議論の結論を示さず、汎用の挨拶で終える |

上の例の出所：[Gemini生成記事](https://qiita.com/robitan/items/76af9fa8b82c0f9c739f)、[Claude生成記事](https://qiita.com/robitan/items/b6cfe30492ba994ed83a)、[GPT生成記事](https://qiita.com/robitan/items/6fdad03576573d539c46)、[AI利用を明示した記事](https://pantograph.co.jp/blog/production/ai-writting.html)。例の引用は短く保ち、必要に応じてリンク先の文脈を読み直す。

## 語句より強い文体上の兆候

- 見出しが毎回「概要→メリット→注意点→まとめ」の型になり、題材固有の問いや書き手の判断が見えない。
- 複数の段落で文の長さ、語尾、接続の順序が揃いすぎる。語尾だけが「です」「ます」などで連続する。
- 「単なるAではなくB」「一方で、〜も重要です」を繰り返すが、Bや留保に新しい根拠がない。
- 各節の末尾で冒頭を言い換え、文章量が増えても情報が増えない。
- 体験談・書評・発表など、本来は立場が見える形式なのに、常に中立的な解説者の声になる。
- 箇条書き、太字、区切り線、絵文字を規則的に重ね、内容の優先順位より体裁が目立つ。

これらは[AI slopの評価研究](https://arxiv.org/html/2509.19163v2)が挙げる反復、定型性、情報密度、文脈に合わないトーンとも整合する。日本語の特定語句に対する統計的な判定基準ではない。

## 成果物別

### 記事

- 冒頭の「近年〜が注目されています」から題材固有の問いまでが長い。
- 一般的な利点・課題を網羅しているが、自分で試した条件、観察、失敗、判断の理由がない。
- 技術的な主張が「活用できる」「効率化につながる」で止まり、何がどう変わるかを述べない。

### 書評

- 本の題名を入れ替えても通る「示唆に富む」「考えさせられた」「幅広い読者におすすめ」が評価の中心になる。
- あらすじや目次の要約はあるが、どの記述に賛成・反対したか、どう読んだかがない。
- 長所と短所を機械的に一つずつ並べ、評者の判断が曖昧になる。
- 引用や内容の正確さは書籍を確認できる範囲で点検する。確認できなければ未検証とする。

書評では要約と評者自身の具体的な評価を区別する。[Purdue OWLの書評ガイド](https://owl.purdue.edu/owl/general_writing/common_writing_assignments/book_reviews.html)を参照。

### スライド

- 各ページが抽象的な見出しと均一な箇条書きで続き、ページごとの結論が見えない。
- 見出し、リード文、図表のキャプションが同じ内容を言い換えるだけになる。
- 図やアイコンが飾りとして増える一方、比較条件、数値、関係、出典を示さない。
- 最終ページが「今後の展望」「一緒に未来をつくる」などの汎用句で終わり、発表の結論に戻らない。

見た目の整い方だけではAIらしさを判定しない。[AI生成スライドの研究](https://juholeinonen.com/assets/pdf/leinonen2026ai.pdf)でも閲覧者は制作元を確実に見分けられず、生成物にも人の編集が必要だった。

## 判定の限界

[日本語文体の分析](https://arxiv.org/abs/2304.05534)では助詞・読点などの分布差が報告されているが、限られたモデルと文章群の研究であり、個別の語句で作者を特定できるわけではない。「人間らしく見える」ために意図的な誤字、無意味な脱線、架空の体験を加えることは提案しない。
