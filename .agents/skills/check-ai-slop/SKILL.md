# AI slopのように見えるか点検する

完成済みの成果物を読み、読者に「AIが書いたような文章」と感じさせる箇所を特定する。制作手段や使用したモデルの鑑定ではなく、文体と内容についての編集上の評価を行う。

## 手順

1. 対象全体を読み、記事・書評・スライドのどれか、想定読者、主張、書き手の立場を把握する。記事・書評は本文まで、スライドは各ページの文面とページ間の流れを見る。表示結果があれば図表も確認する。
2. [文体の実例と点検項目](references/signals.md) の共通項目と該当形式の項目を確認する。表現の出現そのものではなく、反復、文脈との不一致、情報の欠落を根拠にする。
3. 同じ書き手の既存コンテンツが読める場合は語り口、文末、具体例の選び方を比較する。以前と異なるだけでは問題にしない。今回の題材や読者に合っているかを見る。
4. **「AI slopの印象が強い」「一部にAIらしい癖がある」「目立たない」「判定材料が不足」** のいずれかを結論にする。文体上の癖と、内容・根拠の問題を分けて説明する。
5. 問題箇所を短く引用またはページ・段落で示し、読者がどう受け取るかと最小限の改善案を述べる。判定依頼だけならファイルを編集しない。本人の経験、読書感想、実測値、出典を創作しない。

定型句一つや整った構成だけでAI生成と断定しない。短文や未完成の成果物は判定を保留できる。AI生成確率の数値は出さない。
